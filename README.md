# Portfolio — Francisco Piñero Alpañés

Sitio estático para GitHub Pages. Contenedor funcional (contenido + i18n); la dirección visual se define aparte.

## Qué incluye

- Marca pública: Francisco Piñero Alpañés (el usuario de GitHub no aparece en la UI)
- Selector de idioma ES / EN (`?lang=` y `localStorage`)
- Identidad, trayectoria (etapas seleccionables), trabajo público, aptitudes, contacto
- CTA: email; LinkedIn secundario; GitHub solo en el pie; sin teléfono
- HTML/CSS/JS sin build

## Publicar

1. Repo público en GitHub Pages (`main` / raíz, o el flujo que uses).
2. Sitio de usuario: el repo debe llamarse `usuario.github.io`.
3. Sitio de proyecto: la URL incluye el nombre del repo.
